# Controle de Dados para Imposto de Renda

Projeto desenvolvido em Excel para facilitar a organização das informações necessárias para a declaração de imposto de renda.

A planilha reúne dados pessoais, rendimentos, bens e direitos, despesas e documentos em um único arquivo, permitindo acompanhar pendências e conferir os principais valores antes da preparação da declaração.

## Funcionalidades

- cadastro de dados básicos;
- controle de rendimentos e imposto retido;
- registro de bens e direitos;
- organização de despesas e reembolsos;
- checklist de documentos;
- listas suspensas para validação de dados;
- resumo automático de valores e pendências;
- visual simples em preto, branco e cinza.

## Arquivo do projeto

O arquivo principal é `Controle_Dados_Imposto_de_Renda.xlsx`.

## Objetivo

O objetivo é oferecer uma ferramenta simples e prática para centralizar informações fiscais e apoiar a organização dos documentos usados na declaração de imposto de renda.

> A planilha é uma ferramenta de organização de dados e não substitui a orientação de um profissional contábil nem o programa oficial da Receita Federal.
