# Dashboard de Vendas em Excel

Projeto desenvolvido para transformar uma base de dados de vendas em informações visuais claras e úteis para análise de desempenho comercial.

## Objetivo

O dashboard organiza dados brutos e apresenta indicadores e gráficos que ajudam a acompanhar resultados, identificar padrões e apoiar decisões baseadas em dados.

## Funcionalidades

- base de vendas estruturada no Excel;
- cálculo automático de receita, custo e lucro;
- indicadores de receita total, lucro total, margem, quantidade de pedidos e ticket médio;
- análise mensal de faturamento;
- comparação de vendas por categoria;
- desempenho por vendedor;
- distribuição de receita por canal de venda;
- resumo com melhor mês, categoria, vendedor e canal;
- visual simples e profissional em preto, branco e cinza.

## Arquivo

O arquivo principal do projeto é `Dashboard_Vendas_Excel.xlsx`.

## Observação

Os dados utilizados na planilha são fictícios e servem apenas para fins de aprendizado e demonstração.

Inteligência Artificial (IA) e Ciência de Dados.
